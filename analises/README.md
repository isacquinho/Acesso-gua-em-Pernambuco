# Organização das três amostras

Cada pasta contém o script `T7.R`, as planilhas de entrada e de saída, gráficos e mapa HTML correspondentes à amostra. O **script é o mesmo nas três pastas**; as bases `amostra_fixa_municipios.xlsx` e os resultados são diferentes.

| Amostra | Conteúdo | Como executar |
|---|---|---|
| 1 | [Arquivos](amostra-1/) | `cd analises/amostra-1 && Rscript T7.R` |
| 2 | [Arquivos](amostra-2/) | `cd analises/amostra-2 && Rscript T7.R` |
| 3 | [Arquivos](amostra-3/) | `cd analises/amostra-3 && Rscript T7.R` |

O uso de `&&` no exemplo corresponde a um terminal Bash; no Windows PowerShell, execute a mudança de pasta e o `Rscript` em comandos separados. Veja o [guia detalhado](../docs/REPRODUCAO.md).
