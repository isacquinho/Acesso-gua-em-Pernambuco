# Como citar o projeto

## Referência bibliográfica sugerida (formato acadêmico simplificado)

SILVA, Hicaro Raffael Dionizio; OLIVEIRA, Isac Souto de; AHAOLOR, Owah Kingsley. **Uso de métodos estatísticos para entender o papel da variável raça e PIB per capita no acesso ao abastecimento de água em Pernambuco**. Relatório acadêmico, disciplina Métodos Estatísticos, Engenharia de Produção, Universidade Federal de Pernambuco, 2026.

## No GitHub

Se você usar os gráficos, scripts ou resultados, cite **os três autores** e o relatório acadêmico. Utilize também a referência do **IBGE — Censo Demográfico 2022**, conforme a fonte específica dos dados consultados. Evite atribuir ao repositório a autoria de bases estatísticas oficiais ou de publicações citadas na bibliografia.

Um arquivo [`CITATION.cff`](../CITATION.cff) foi incluído para facilitar a opção *Cite this repository* do GitHub. Ele não estabelece, por si só, qualquer licença de reutilização.
